# 🖥️ Windows Server — Active Directory

> **Projet personnel — Mise en place et découverte d'un environnement Active Directory avec Windows Server 2022**

## 📖 Introduction

Ce projet est un **laboratoire personnel** réalisé avec **Windows Server 2022 et VirtualBox**, dans le but de découvrir et de comprendre les bases de l'**administration système et réseau** dans un environnement Microsoft.

Au cours de ce projet, je mets progressivement en place un environnement **Active Directory Domain Services (AD DS)** : installation du serveur, configuration réseau, création d'un domaine, utilisateurs, groupes et unités organisationnelles.

L'objectif n'est pas seulement de suivre des procédures, mais de **comprendre ce que je fais**, pourquoi chaque élément est nécessaire, et de documenter mon apprentissage au fur et à mesure.

Les erreurs rencontrées, leurs recherches et leurs solutions sont également conservées afin de garder une trace de ma progression.

---

## 🎯 Objectifs

* Découvrir Windows Server 2022
* Comprendre Active Directory et AD DS
* Mettre en place un Domain Controller
* Comprendre les domaines, OU, groupes et utilisateurs
* Découvrir le fonctionnement du DNS dans Active Directory
* Expérimenter avec les GPO et les permissions
* Développer mes compétences en administration système et réseau
* Documenter ma progression et les problèmes rencontrés
